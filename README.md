# CD Food Cooldown — rebuilt for game build 2026-09-04

Rebuilt offsets for **[CD Food Cooldown](https://www.nexusmods.com/crimsondesert/mods/3090)** by Rogue69 (Nexus mod 3090).

The original mod was built against the pre-2026-09-04 Crimson Desert build. After the 2026-09-04 game update it no longer applies correctly, and mounting it through DMM **causes the game to crash**. These files do the same thing — set the shared food cooldown — with every offset re-derived against the current build.

> **Not my mod.** All credit for the original goes to Rogue69. This repository contains only regenerated offset tables.

## Install

1. Copy **one** file into your DMM `mods/` folder.
2. Enable it in DMM and mount.
3. Check `mount_log.txt` — it should report **no** `pattern not found` errors and **no** `pattern scan applied` lines. If either appears, unmount and do not play.

Only enable one at a time. All five patch the same 1431 byte positions, so two enabled at once will fight over the same offsets.
